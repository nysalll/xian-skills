## 实测暴露的问题与本仓库修复

| 实测反馈 | 修复措施 |
| --- | --- |
| `xian query --link 97104` 仅命中 1 条，遗漏 `icon_path`、`lingyu`（顶层 `list` 表）、`lingyu_config`（嵌套 `dict`）、`reward_part23`（奖励数组）及 `item` 内的 `icon` 字段 | 重构 `link_id`：支持 `dict` 与 `list` 递归遍历、顶层数组表、嵌套路径生成及深度限制；区分 `semantic_reference`（明确引用）与 `value_match`（仅数值相等的候选关联），支持 `--link-mode all\|semantic` |
| 静态导表未区分“非空表”“运行时生成/分片表”与“空表” | `export_table`、`export_tree` 与 `build_catalog` 增加 `data_status`（`nonempty`、`runtime_generated`、`empty`、`logic_skipped`）及 `part_pattern` 提示，不执行不受信任的游戏 Lua 代码 |
| 没有反编译器时玩家不易自行查找可信二进制 | `xian tools decompiler` 展示 `marsinator358/luajit-decompiler-v2`（MIT，`Mar_24_2024`）信息与 SHA256，仅在 `--install --yes` 时下载并校验 |
| WorkBuddy 目录与启动器路径问题，以及 Windows 路径反斜杠转义异常 | WorkBuddy 用户级目录固定为 `~/.workbuddy/skills/`，ZIP 顶层直接为技能文件夹；修复 `installers/windows/xian.cmd` 的 `cmd.exe` 变量延迟展开问题，同时生成 `xian.cmd`、`xian.ps1`、`xian`（POSIX shell）；新增 `normalize_path` 统一处理 Windows 反斜杠、末尾引号、环境变量与 `config.json` 单反斜杠容错 |
| Android SDK ADB 34.0.1 与 MuMu ADB 36.0.0 并存导致设备偶发 `offline` | 已有 ADB 服务在跑时继续复用同一 `adb.exe`，无服务时优先使用 MuMu 自带 ADB；遇到 `offline` 时明确诊断原因，不擅自杀掉其他程序的 ADB Server |
| 状态展示中版本号、快照份数与 `version.txt` 行数易混淆 | `status` 与 `client version` 明确区分 `current_version`、本机完整快照份数（`complete_count`）与 `version_txt_line_count` |

以上第二台电脑的实测结果来自外部机器报告，仓库中未附带任何客户端资源、设备标识或私人路径。
