# 隐私和安全边界

这些工具只处理用户自己有权访问的客户端和自己的会话。

允许：

- 用 adb 读取本机模拟器里自己安装的游戏文件
- 解密本地 AssetBundle，导出配置和资源
- 在用户确认后，于本机录制自己的流量并解析
- 在用户确认后，查看本机进程；安装了 Frida 时只列出相关模块名和少量导出是否存在

不允许，代码里也没有这些功能：

- 登录别人的账号，或保存、猜测密码去登录
- 绕过反作弊、修改战斗结果、调用 Lua 虚拟机去执行游戏逻辑
- 攻击游戏服务器，或读取其他玩家的数据
- 把抓包、解码结果或客户端资源上传到外部服务

抓包目录里的口令、token、cookie、session 一类字段会写成 `[redacted]`。角色标识可能仍在本地 jsonl 里，因为战斗研究需要它。这个目录默认不进 Git。不要把它发给别人。

`adb root`、tcpdump、Frida attach 和整包复制都会改动或读取大量本地数据，所以必须 `--yes`。

客户端里的系数、奖励和活动表是客户端配置。报告要分开写：

- 已确认事实
- 有证据支持的推断
- 待验证假设
- 当前无法判断

看不到的服务器随机、个人限购和最终结算，保持为无法判断。
