## 跨渠道差异，不是历史更新

`xian updates history --channel official` 和证道服都是 `comparable: false`。每一边只有一个完整版本，所以不能写“证道服这次更新了什么”。

`xian updates records --relation cross-channel` 比较的是两边的配置表。报告写明：这是横向差异，不是某一边的历史补丁。547 张表有差异，其中活动 36 张有记录变化、2 张只在证道服出现，神通 28 张有变化、8 张为证道服新增，奖励 60 张有变化。

`item.lua` 两边都是 12069 条，解析后的记录相同。文件字节不同，是因为 JSON 键顺序不同，不是道具条目不同。

## Cursor Skill

`%USERPROFILE%\.cursor\skills\xian\SKILL.md` 和项目里的 `.cursor\skills\xian\SKILL.md` 都在。再次安装用户技能时，工具返回 `invocation_verified: false`。

这一轮对话没有把 `xian` 放进已加载的技能列表，所以不能把“我运行了 CLI”写成“Cursor 触发了 Skill”。要验证触发，需要新开一个 Agent 对话，问“用 xian 查正式服里的青铜丹房”，看它是否先读 `SKILL.md` 再调用 `xian query`。

安装只复制了本仓库的 `xian*` 技能。内容不同时会先备份到 `%USERPROFILE%\.xian-skills\backup\`。

## 视频

本机没有 `ffmpeg`。USM 已拆成 IVF，转 MP4 的代码会在缺少 ffmpeg 时停住。没有安装新的系统软件。若要补这一步，需要你同意安装来源明确的 ffmpeg，例如从 https://www.gyan.dev/ffmpeg/builds/ 或 `winget install Gyan.FFmpeg` 安装后，把 `ffmpeg.exe` 写进配置的 `ffmpeg_path`。

## 需单独授权的操作说明

1. 抓包录制：`xian capture start --session <名字> --device 127.0.0.1:7555 --yes`。影响：可能执行 `adb root` 并在模拟器里启动 `tcpdump`，数据保存到 `%USERPROFILE%\.xian-skills\data\captures\`，不上传。
2. 进程与模块检查：`xian runtime probe --pid <游戏进程> --yes`。影响：本机 Frida 附加并仅读取模块名与少量导出是否存在。虚拟环境默认不安装 `frida`。
