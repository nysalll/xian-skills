# xian-events

```powershell
xian events analyze --tables <导表目录> --other <另一套导表> --output <活动.md> --json
```

流程：

- 按表名和字段找到活动、商店、任务、奖励和兑换。
- 能确定的数量直接加总，并写上道具名（配置里有名字时）。
- 概率、保底、个人限购和服务器条件单独列为假设。
- 两侧都有导表时说明新增、删除和内容变化。
- 缺表时告诉用户要先 `xian lua tables`，不要编造奖励。
